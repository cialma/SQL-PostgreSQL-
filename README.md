# SQL / PostgreSQL: база данных сотрудников и аналитические запросы

Проект реляционной базы данных для работы с информацией о сотрудниках, подразделениях, должностях, премиях и начислениях.

## Задача проекта

Разработать структуру базы данных для хранения кадровой информации и использовать SQL для решения аналитических и операционных задач.

## Что реализовано

- создание связанных таблиц;
- PRIMARY KEY и FOREIGN KEY;
- загрузка и обновление данных;
- SELECT, INSERT, UPDATE;
- JOIN нескольких таблиц;
- GROUP BY и HAVING;
- агрегатные функции;
- CTE и VIEW;
- оконные функции;
- пользовательские функции на PL/pgSQL.

## Использованные технологии

- PostgreSQL
- SQL
- PL/pgSQL
- CTE
- Window Functions
- Relational Database Design
